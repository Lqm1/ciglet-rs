# ciglet-rs

A Rust reimplementation of the complete public ciglet signal-processing functionality. Upstream: https://github.com/Sleepwalking/ciglet.

The port is in progress. Statistics, f32/f64 precise and level-two window functions, centered zero-padded frame extraction, and reusable f32/f64 complex FFTs are implemented. FftPlan preserves unnormalized forward and length-normalized inverse transforms, optional zero input components, and in-place operation. FFT frequency shifting supports odd and even lengths. A direct normalized inverse DFT supports arbitrary positive lengths, preserving upstream scalar phase precision and accumulation order. RustFFT provides reusable plans, preallocated scratch storage, and CPU-selected SIMD with scalar fallback. The original approximate-cosine DCT-II and level-two sine/cosine approximations are also implemented, including the original small deviation at cos(0). Reusable chirp-z plans support arbitrary positive lengths and frequency steps, including the original inverse convention. Centered single/multiple sinusoid synthesis uses the original recurrence, applies amplitude correctly, and safely handles zero/one sample lengths. Bounded WAV reading supports PCM and IEEE float32/float64, mono/stereo left-channel selection, and extensible formats, with documented decoding corrections. Mono PCM8/16/24/32 writing provides corrected defaults and explicit legacy byte-compatible options. Reusable forward STFT supports arbitrary centered frames, variable window lengths, optional magnitude/phase outputs, mean removal, and explicit overlap normalization. Odd windows and variable-window factors have safe corrected behavior. Inverse STFT retains approximate polar conversion, normalized inverse transforms, endpoint fades, offsets, and overlap-add. The default preserves Nyquist energy; explicit Legacy policy reproduces the original overwrite. FrameGrid provides the original regular-grid Blackman analysis and 32-sample-fade synthesis workflows with checked dimensions. Mel/Bark conversions, mel-spaced frequency points, equal-loudness weights, and the original level-two logarithm/exponential/power approximations are implemented with retained scalar rounding. Owned mel/PLP filterbanks support construction, custom response/support configuration, spectrum and spectrogram application, logarithmic or PLP compression, and corrected small-grid boundaries. Spectrogram output uses one flat allocation. Band-feature cepstral conversion retains the source approximate DCT, order clamping and final DC placement, with requested-coefficient and complete legacy buffer APIs plus flattened matrix conversion. Typed windowed FIR design, full linear convolution without a padded input copy, and antialiased Lanczos resampling are implemented for f32/f64. Resampling defaults to corrected first-sample inclusion and offers an explicit original boundary policy. See docs/filter-resample-compatibility.md for cutoffs, measured errors and reference reproduction. The remaining DSP algorithms, other approximation variants, and plotting integrations are pending.
